# CampusSync AI 🚀
### Institutional Document Automation Suite for SMVEC Students

CampusSync AI is a high-performance, full-stack automation tool designed to streamline administrative paperwork for engineering students. Built with a "Mobile-First" approach, it allows users to instantly generate professionally formatted documents for college submission.

## 🌟 Key Features
*   **One-Click Generation**: Instant drafting of Leave Letters, Bonafide Certificate Requests, and Internship NOCs.
*   **SMVEC Optimized**: Templates pre-configured for **Sri Manakula Vinayagar Engineering College** departments and HOD requirements.
*   **Cinematic UI**: A modern, dark-mode dashboard featuring responsive "Quick Action Chips."
*   **Offline-Smart Logic**: Operates without expensive LLM API costs, making it ideal for low-resource/hostel network environments.
*   **Zero-Footprint Design**: Lightweight architecture that runs efficiently on local machines or free-tier cloud hosting.

## 🛠️ Tech Stack
*   **Frontend**: React.js (Vite), Tailwind CSS, Lucide-React
*   **Backend**: Node.js, Express.js
*   **State Management**: React Hooks
*   **Styling**: Modern CSS-in-JS (Tailwind Utility Classes)
